## Run locally

You need Python 3 installed. Get the project files using either option:

**Clone with Git:**

```bash
git clone https://github.com/bertwork/soniq.git
cd soniq
```

**Or download as a ZIP:** [Download Soniq](https://github.com/bertwork/soniq/archive/refs/heads/main.zip), then extract the ZIP and open a terminal in the extracted `soniq` folder.

From the project folder, install Flask and start the app:

```bash
python -m pip install Flask
python app.py
```

When the server starts, open [http://127.0.0.1:5000](http://127.0.0.1:5000/) in your browser. Stop the server with `Ctrl+C`.
